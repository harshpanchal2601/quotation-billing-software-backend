Evidence rules

For each future run record candidate commit/artifact identity, runtime/DB/browser
versions, exact authorized command, isolated environment, synthetic fixture seed,
time, expected/actual result, redacted output, failure issue and reviewer. Record
SKIPPED separately from PASSED. A missing optional database URL currently skips
its suite: a green aggregate without those suites is not integration acceptance.
Use dedicated wave-specific local disposable database names accepted by each
suite's guard. Migrate each through the full current schema and generate the
matching client first; old wave fixtures now reference newer relations. Never
fall back to the application's DATABASE_URL or point a restore clone at live
SMTP/payment/tax/AI/webhook providers. No migrations are performed by the fixture.

platform-entitlements.mysql.test.ts and wave04..wave10.mysql.test.ts.

For EVERY API family in wave-11-source-inventory.txt expand each declared or
loop-generated endpoint, and record these cases independently:
- A admin/user cannot list/count/search/read/export/mutate B data.
- Foreign direct and nested company/item/unit/warehouse/owner/source/file IDs.
- Actor A cannot get another actor's private imports/keys/webhooks/jobs/views.
- Firm-header/body spoofing cannot override a firm user, portal session or key.

- Portal contact sees only explicit company/revision grants; revoked identity,

- Private documents/attachments/artifacts cannot be reached by public static
  paths; active public branding/image rules do not grant private downloads.
- Audit/history/error/CSV/PDF/preview/options cannot leak foreign joins or totals.

Keep realistic distinguishable A/B values, similar names, separate currencies,
different roles and source counts. Compare denied bodies, pagination and timing
where meaningful. Negative assertions must prove absence of foreign output and
absence of effects; a generic status assertion alone is not a full proof.
Existing tests do not yet prove every line of this full matrix.
